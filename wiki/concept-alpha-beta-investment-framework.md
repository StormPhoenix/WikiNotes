# Alpha / Beta 个人投资分析框架

## 定义

Alpha / Beta 个人投资分析框架，是指个人投资者在分析个股和市场时，把收益来源拆分为 [[concept-alpha-in-investing|Alpha]]、[[concept-beta-in-investing|Beta]]、估值变化和随机波动，并据此制定买入、持有、跟踪和复盘计划的方法。

核心目的：区分个人能力与市场馈赠，区分判断错误与环境逆风。

## 收益拆解

```text
个股收益
= 市场 beta
+ 行业 beta
+ 风格 beta
+ 主题 beta
+ 宏观 beta
+ 个股 alpha
+ 估值变化
+ 随机波动 / 运气
```

## 分析路径

1. **识别机会类型**：个股 alpha、行业 beta、风格 beta、主题 beta，还是混合机会？
2. **事前提出 alpha 假设**：公司相对市场和同行，有什么尚未被充分定价的独特变化？
3. **分析 beta 环境**：大盘、行业、风格、主题、宏观、政策是否顺风？
4. **检查估值和定价**：好处是否已经被市场充分反映？当前价格隐含了什么预期？
5. **制定仓位和验证计划**：alpha 如何验证？beta 何时反转？错了怎么办？仓位为什么这么大？
6. **事中跟踪**：alpha 是否兑现？beta 是否变化？估值是否透支？
7. **事后复盘**：收益来自能力、市场、风格、主题、运气，还是估值变化？
8. **沉淀经验**：可复制的加入方法库，不可复制的归为运气。

## Alpha / Beta 矩阵

| 组合 | 含义 | 策略 |
|---|---|---|
| 强 alpha + 强 beta | 公司自身有超预期变化，市场/行业/风格也顺风 | 最理想，可考虑较高仓位，但仍要看估值 |
| 强 alpha + 弱 beta | 公司不错，但环境不好 | 分批、轻仓、等待 beta 企稳，重点跟踪 alpha 是否兑现 |
| 弱 alpha + 强 beta | 公司一般，但行业/主题/风格很强 | 可以交易，但不能信仰；重点看主题阶段和拥挤度 |
| 弱 alpha + 弱 beta | 公司无明显优势，环境也差 | 回避 |

## 仓位公式

```text
仓位 = alpha 确定性 × beta 顺风程度 × 估值安全边际
```
