# 长鑫科技

## 概述

长鑫科技是资料中讨论的国产 DRAM 龙头和国家战略硬科技资产。市场围绕它形成的核心叙事包括：国产 DRAM 龙头、中国大陆存储产业核心资产、半导体自主可控、科创板重磅 IPO、A 股稀缺硬科技核心资产。

## 关键属性

- 行业：半导体制造、存储芯片、DRAM；
- 资产属性：国家战略硬科技成长股、国产替代资产、存储周期股、科创板稀缺龙头；
- 与传统 [[concept-zhongtegu|中特估]] 的关系：具有“中特估式”的国家战略叙事，但不是传统低估值央国企高股息资产；
- 估值核心：国产替代、DRAM 周期、技术追赶、资本开支、客户导入、产业安全和科技行情风险偏好。

## 与中特估的区别

| 传统中特估 | 长鑫科技 |
|---|---|
| 多为央企、国企、金融、能源、通信、基建、公用事业 | 半导体制造、存储芯片、硬科技公司 |
| 核心逻辑是低估值修复 | 核心逻辑是国产替代、技术突破、成长预期 |
| 常见特征是低 PB、低 PE、高股息 | 上市时往往是高关注、高估值、高预期 |
| 重视现金流、分红、ROE、市值管理 | 重视研发、产能、良率、技术代际、资本开支 |
| 估值波动通常较低 | 半导体周期波动很强 |

## 估值关注点

1. DRAM 价格处于周期上行、中段还是顶部；
2. AI/HBM 是否挤占传统 DRAM 产能，还是带来整体产能扩张；
3. 三星、SK 海力士、美光的资本开支是否重新加速；
4. 国产替代需求能否抵御全球周期下行；
5. 制程节点、良率、单位成本、产能利用率和客户认证；
6. 当前市值是否已经把技术追赶成功、国产替代兑现和周期上行全部计入。
