# 生猪育种金字塔体系

## 定义

现代商业化猪场的育种体系采用金字塔结构，从顶端的核心育种群到底端的商品代，逐级杂交扩繁，实现基因改良与生产效率的平衡。

## 体系结构

```
核心群（纯种）→ 祖代群（纯种扩繁）→ 父母代（二元母猪）→ 商品代（三元 DLY）
```

| 层级 | 品种 | 作用 |
|------|------|------|
| 核心群 | 杜洛克、长白、大约克夏纯种 | 基因选育，不断改良 |
| 祖代群 | 纯种 | 纯种扩繁 |
| 父母代 | 二元母猪（长白×大约克夏） | 实际产仔的"能繁母猪" |
| 商品代 | DLY 三元杂交猪 | 全部育肥出栏，不留种 |

DLY 三元杂交：父本杜洛克（D）× 母本二元母猪（长白 L × 大约克夏 Y），综合三品种优势。

## 三元母猪不留种的原因

| 问题 | 说明 |
|------|------|
| 基因分离 | 三元基因组合不稳定，后代性状分化严重 |
| 繁殖性能下降 | 窝产仔数、母性、泌乳力均不如二元母猪 |
| 生长优势丧失 | 杂交优势在下一代大幅衰减 |
| 毛色杂乱 | 杜洛克含红色基因，后代可能出现花斑、红毛 |

> 例外：2019 年非洲猪瘟期间，母猪极度短缺，很多猪场被迫留三元母猪做种，导致行业 [[concept-psy-pigs-per-sow-per-year|PSY]] 从 20+ 暴跌到 16-18，花了两年才恢复。

## 后备母猪选留标准

| 标准 | 要求 |
|------|------|
| 乳头数 | 至少 7 对（14 个）以上有效乳头 |
| 外阴 | 发育正常 |
| 肢蹄 | 四肢健壮，无跛行 |
| 品种 | 母亲是二元、父亲是纯种长白或大约克夏（不能是杜洛克） |
