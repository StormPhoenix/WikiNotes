# 屠宰业务

## 定义

屠宰业务是连接生猪养殖端和消费端的核心中游环节，将活猪加工成可流通的肉产品和副产品。完整流程包含七步：验收静养→致晕放血→烫毛/剥皮→开膛取内脏→劈半冷却排酸→分割→包装冷链。

## 完整流程

| 步骤 | 内容 | 关键点 |
|------|------|--------|
| 1. 验收静养 | 查验证件、停食12-24h、淋浴 | 非瘟检测报告是第一道关 |
| 2. 致晕放血 | 电击/CO₂致晕→刺杀放血 | 动物福利：先致晕后放血 |
| 3. 烫毛/剥皮 | 烫毛(60-65°C)→打毛 或 机械剥皮 | 刨毛猪为主流工艺 |
| 4. 开膛取内脏 | 剖腹取出内脏，白脏红脏分离 | 同步检验，病变即时剔除 |
| 5. 劈半排酸 | 纵向劈半→0-4°C冷却12-24h | **冷却排酸是技术核心** |
| 6. 分割 | 按GB/T 40466-2021分割成标准件 | 五号肉（里脊）价值最高 |
| 7. 包装冷链 | 热鲜/冷鲜/冻肉三种形态 | 冷鲜肉占比从40%→60%(2030E) |

## 产品体系

### 主产品

| 产品 | 说明 | 占收入比 |
|------|------|---------|
| 白条猪（片猪肉） | 劈半后未分割的整片 | 30-40% |
| 分割肉 | 按部位分割的标准化产品 | 40-50% |
| 冷鲜肉 | 冷却排酸后的鲜猪肉 | 增长最快 |

### 副产品

| 类别 | 用途 |
|------|------|
| 内脏（心肝肺胃肠） | 食用/加工 |
| 头蹄 | 食用 |
| 猪皮 | 皮革工业 |
| 骨类 | 骨汤/饲料 |
| 血液 | 血豆腐/饲料 |
| 腺体（胰腺等） | 生物制药（胰岛素原料） |

> 副产品收入可达总收入的 10-15%。双汇副产品利用率 92%。纯养殖企业卖活猪时副产品价值无法单独定价，自建屠宰后可独立销售。

## 盈利模式

### 核心指标：毛白差

```
毛白差 = 白条猪价格 - 活猪（毛猪）价格
```

| 时期 | 毛白差 | 状态 |
|------|--------|------|
| 2025年1-4月 | 4.70 元/kg | 微利 |
| 2025年5-7月 | 3.80-4.50 元/kg | 亏损 |
| 正常年份 | 5-7 元/kg | 盈利 |

### 终端价格刚性

猪价涨 67% → 猪肉零售价只涨 35%。消费者对猪价不敏感，导致：
- 猪价低 → 毛白差大 → 屠宰赚钱
- 猪价高 → 毛白差小 → 屠宰亏钱

### 屠宰 vs 深加工利润

| 业务 | 毛利率 | 利润贡献 |
|------|--------|---------|
| 屠宰（生鲜冻品） | 5-8% | 低 |
| 肉制品深加工 | 25-30% | **高** |

> 屠宰是"通道费"——获取低价原料，加工成肉制品后赚高毛利。

### 产能利用率生死线

| 产能利用率 | 状态 |
|-----------|------|
| >70% | 盈利 |
| 50-70% | 微利 |
| 20-30% | 亏损（2025年行业平均） |
| <20% | 危险 |

## 三种商业模式

| 模式 | 代表 | 特点 |
|------|------|------|
| 全产业链 | 牧原 | 养殖→屠宰一体化，平滑猪周期 |
| 屠宰+深加工 | [[entity-shuanghui-fazhan|双汇发展]] | 采购活猪→屠宰→深加工→品牌渠道 |
| 纯屠宰 | 中小屠宰场 | 赚毛白差，受猪价波动影响最大 |
