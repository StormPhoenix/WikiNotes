# 投资收益归因复盘

## 定义

投资收益归因复盘，是指在交易结束或阶段性复盘时，不只问“赚了还是亏了”，而是拆解收益或亏损来自市场 beta、行业 beta、风格/主题 beta、个股 alpha、估值变化还是运气/噪音。

## 收益拆解公式

```text
最终收益
= 市场 beta
+ 行业 beta
+ 风格/主题 beta
+ 个股 alpha
+ 估值变化
+ 运气/噪音
```

## 赚钱时要问

1. 是整个市场都涨了吗？
2. 是行业都涨了吗？
3. 是风格或主题都涨了吗？
4. 我的个股是否明显跑赢同行？
5. 跑赢来自我事前判断的 alpha 吗？
6. 还是因为临时消息、情绪、运气？
7. 如果再来一次，这个判断能复制吗？

## 亏钱时要问

1. 是大盘拖累？
2. 是行业 beta 逆风？
3. 是风格切换？
4. 是主题退潮？
5. 是我买贵了？
6. 是个股 alpha 被证伪？
7. 是仓位过重？
8. 是我把 beta 当成 alpha？

## 复盘目标

- 可复制的能力：加入方法库；
- 不可复制的收益：归为运气，不要过度自信；
- 判断错误：修正分析框架；
- 买贵或仓位错：改进交易和风控。
