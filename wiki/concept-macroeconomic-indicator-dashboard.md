# 宏观经济指标仪表盘

## 定义

宏观经济指标仪表盘，是指用一组固定指标持续跟踪经济运行状态的方法。它帮助初学者避免只看单一数据，而是从增长、通胀、就业、利率、财政、汇率等多个角度理解经济。

## 美国宏观核心指标

| 模块 | 重点指标 |
|---|---|
| 增长 | GDP、零售销售、ISM PMI |
| 通胀 | CPI、PCE、核心 PCE |
| 就业 | 非农就业、失业率、平均时薪、初请失业金 |
| 利率 | 联邦基金利率、2 年期和 10 年期美债收益率 |
| 消费 | 零售销售、个人消费支出 |
| 房地产 | 新屋销售、成屋销售、房价、房贷利率 |
| 金融市场 | 美元指数、美股、美债、信用利差 |

## 中国宏观核心指标

| 模块 | 重点指标 |
|---|---|
| 增长 | GDP、工业增加值、服务业生产指数 |
| 消费 | 社会消费品零售总额 |
| 投资 | 固定资产投资、制造业投资、基建投资、地产投资 |
| 地产 | 商品房销售面积、房价、房企融资、土地成交 |
| 通胀 | CPI、PPI |
| 就业 | 城镇调查失业率、青年失业率、居民收入 |
| 金融 | 社融、M2、人民币贷款、LPR |
| 外贸 | 出口、进口、贸易顺差、人民币汇率 |
| 财政 | 公共财政收入、土地出让收入、专项债 |

## 解读原则

- **看组合，不看孤立指标**：例如就业要同时看新增就业、失业率、工资和劳动参与率。
- **看趋势，不只看单月波动**：单月数据可能受季节、天气、统计修正影响。
- **看预期差**：市场经常反应“实际数据 - 市场预期”，而不只是数据本身好坏。
- **看政策含义**：数据最终会影响市场对央行、财政和监管政策的判断。
- **看国家差异**：美国更重视消费、就业、通胀和美联储；中国更重视地产、信贷、投资、出口和政策协调。
