# 从财报推算年度员工薪酬总额

## 定义

通过资产负债表的**应付职工薪酬**期初期末余额（A、B）和现金流量表的**支付给职工以及为职工支付的现金**（C），反推企业年度薪酬总额（即本年计提额）。

## 核心要点

### 公式

```
员工本年度薪酬总额 = A - B + C
```

- A = 应付职工薪酬期末余额
- B = 应付职工薪酬年初余额
- C = 现金流量表"支付给职工以及为职工支付的现金"

### 水缸模型

应付职工薪酬是负债类账户，像一个水缸：

| 事件 | 影响 | 水缸比喻 |
|------|------|---------|
| 本年计提薪酬（员工干活，企业新增欠款） | 余额增加 | 注水 ← **这是目标** |
| 本年实际支付薪酬（企业掏现金） | 余额减少 | 放水 |

等式推导：

```
年初余额 + 本年计提 - 本年支付 = 年末余额
  B     +   ?     -    C      =   A

→ 本年计提 = A - B + C
```

即：**灌水量 = 水位变化 + 放水量**

### 数字举例

- 年初余额 B = 100万（去年12月工资还没发）
- 本年支付现金 C = 500万
- 年末余额 A = 80万（今年12月工资还没发）
- 薪酬总额 = 80 - 100 + 500 = **480万**

验证：年初欠100万 + 今年产生480万 - 今年支付500万 = 年末欠80万 ✅

## 常见误区

### 误区：B - A = C

> "年初欠 B，年末欠 A，那今年支付的就是 B - A = C"

**错误原因**：假设了账户一年只发生"付钱"一件事，遗漏了"本年计提"——员工今年干了一整年的活，企业新欠了一大笔薪酬。C（现金支付）里既包含支付去年欠款的部分，也包含支付今年薪酬的部分。

### 通用性

"期末 - 期初 + 本期减少 = 本期增加"是所有**负债类账户**的通用等式。不仅适用于应付职工薪酬，应付账款、应交税费等都可以用同样思路反推本期发生额。
