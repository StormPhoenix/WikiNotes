# 猪肉屠宰业务知识全景

> 本文整理了猪肉屠宰业务的完整知识体系，涵盖屠宰流程、产品体系、盈利模式、行业竞争格局，以及屠宰业务平滑猪周期的核心逻辑。适用于生猪产业投资研究的背景知识储备。

---

## 1. 屠宰业务在产业链中的位置

```
上游（养殖端）          中游（屠宰加工）           下游（消费端）
                        
种猪繁育                ┌──────────────┐         农贸市场
商品猪育肥    ──→       │   屠宰企业     │  ──→    超市
生猪出栏                │              │         餐饮企业
                        │  宰杀→分割→冷却  │         食品加工厂
                        │  →包装→冷链配送  │         预制菜企业
                        └──────┬───────┘
                               │
                          副产品加工
                        （猪皮、内脏、骨、血）
                               │
                          生物医药/饲料
```

屠宰是连接养殖端和消费端的**核心枢纽**——把活猪变成可流通的肉产品，同时产出大量副产品。屠宰企业的经营能力直接决定了从"猪"到"肉"这一段链条的效率和利润分配。

## 2. 屠宰业务完整流程

### 第一步：生猪验收与静养

| 环节 | 内容 | 要点 |
|------|------|------|
| 生猪验收 | 查验检疫合格证、非洲猪瘟检测报告 | 不合格生猪拒收，食品安全第一道关 |
| 停食静养 | 宰前停食 12-24 小时，仅给饮水 | 排空胃肠道内容物，减少屠宰污染风险，降低应激 |
| 宰前淋浴 | 清洗猪体表面污物 | 降低屠体带菌量 |

### 第二步：致晕与放血

| 环节 | 内容 |
|------|------|
| 致晕（击晕） | 电击或二氧化碳致晕，让猪失去意识但不致死 |
| 刺杀放血 | 在致晕后迅速刺杀放血，沥血时间约 5-8 分钟 |
| 动物福利 | 现代屠宰要求"动物福利屠宰"——先致晕后放血，减少痛苦 |

### 第三步：烫毛/剥皮与胴体处理

| 工艺 | 适用场景 | 流程 |
|------|---------|------|
| **刨毛猪**（主流） | 中国绝大部分屠宰场 | 烫毛（60-65°C热水）→ 打毛机脱毛 → 燎毛 → 刮黑 → 清洗 |
| **剥皮猪** | 部分地区/出口市场 | 机械剥皮 → 去头蹄 → 胴体清洗 |

### 第四步：开膛与内脏处理

| 环节 | 内容 |
|------|------|
| 开膛取内脏 | 沿腹中线剖开，取出心、肝、肺、胃、肠等内脏 |
| 内脏分离 | 白脏（胃、肠）与红脏（心、肝、肺）分开处理 |
| 检验 | 同步检验胴体和内脏，发现病变即时剔除 |

### 第五步：劈半与冷却排酸（关键环节）

| 环节 | 内容 |
|------|------|
| 劈半 | 沿脊椎中线纵向锯成两半，成为"白条"（片猪肉） |
| **冷却排酸** | 进入 0-4°C 冷却间，放置 12-24 小时 |

> **冷却排酸是屠宰业务的技术核心**——猪宰后肌肉中糖原分解产生乳酸，使肉 pH 下降。排酸后的肉口感更嫩、更安全、保质期更长。

### 第六步：分割

按国标 GB/T 40466-2021 执行：

| 分割部位 | 商业名称 | 价值 |
|---------|---------|------|
| 一号肉 | 前腿肉 | 中等 |
| 二号肉 | 前排肉 | 中等 |
| 三号肉 | 大排肉/通脊 | 较高 |
| 四号肉 | 后腿肉 | 中等 |
| 五号肉 | 里脊/小里脊 | **最高** |
| 五花肉 | 腹部肉 | 高 |
| 排骨/肋排 | 骨类 | 中高 |
| 肥膘/板油 | 脂肪 | 低 |

### 第七步：包装与冷链

| 产品形态 | 处理方式 | 保质期 |
|---------|---------|--------|
| 热鲜肉 | 宰后不冷却直接销售 | 1-2 天 |
| **冷鲜肉** | 冷却排酸后 0-4°C 保鲜 | 7-10 天 |
| 冻肉 | -18°C 冷冻 | 6-12 个月 |

> 冷鲜肉市场份额 2025 年约 40%，预计 2030 年达 60%。

## 3. 屠宰企业的产品体系

### 主产品

| 产品 | 说明 | 占收入比 |
|------|------|---------|
| **白条猪**（片猪肉） | 劈半后未分割的整片 | 约 30-40% |
| **分割肉** | 按部位分割的标准化产品 | 约 40-50% |
| 冷鲜肉 | 冷却排酸后的鲜猪肉，溢价较高 | 增长最快 |

### 副产品

| 类别 | 具体产品 | 用途 |
|------|---------|------|
| **内脏类** | 心、肝、肺、胃、肠 | 食用/加工 |
| **头蹄类** | 猪头、猪蹄、猪尾 | 食用 |
| **皮毛类** | 猪皮 | 皮革工业 |
| **骨类** | 骨头、骨髓 | 骨汤/饲料 |
| **血液** | 猪血 | 血豆腐/饲料 |
| **腺体** | 胰腺、甲状腺 | 生物制药（胰岛素原料等） |

> 双汇发展的副产品利用率已提升至 92%，一头猪的副产品收入可达总收入的 10-15%。

## 4. 屠宰企业的盈利模式

### 核心指标：毛白差

```
毛白差 = 白条猪价格 - 活猪（毛猪）价格
```

| 时期 | 毛白差 | 屠宰企业状态 |
|------|--------|-------------|
| 2025年1-4月 | 4.70 元/公斤 | 微利 |
| 2025年5-7月 | 3.80-4.50 元/公斤 | **亏损** |
| 正常年份 | 5-7 元/公斤 | 盈利 |

### 终端价格刚性

猪价从 12 涨到 20 涨了 67%，但猪肉零售价从 17 涨到 23 只涨了 35%。消费者不会因为活猪涨价 67% 就愿意多付 67% 买猪肉。

- **猪价低 → 毛白差大 → 屠宰赚钱**（低价原料，肉价跌得少）
- **猪价高 → 毛白差小 → 屠宰亏钱**（高价原料，肉价涨不动）

### 收入构成（以双汇发展为例）

| 业务板块 | 2024年收入 | 占比 | 毛利率 | 利润贡献 |
|---------|-----------|------|--------|---------|
| **屠宰业务**（生鲜冻品） | ~300 亿 | ~50% | ~5-8% | 低 |
| **肉制品业务**（深加工） | ~280 亿 | ~47% | ~25-30% | **高** |
| 其他 | ~20 亿 | ~3% | — | — |

> 屠宰业务收入大但毛利率极低（5-8%），真正赚钱的是**肉制品深加工**（毛利率 25-30%）。屠宰更多是"通道费"——通过杀猪获得低价原料，加工成肉制品后赚高毛利。

### 产能利用率——生死线

| 产能利用率 | 状态 | 说明 |
|-----------|------|------|
| >70% | 盈利 | 固定成本被充分摊薄 |
| 50-70% | 微利 | 勉强覆盖固定成本 |
| **20-30%** | **亏损** | 2025 年行业平均 |
| <20% | 危险 | 严重产能过剩 |

## 5. 屠宰行业的竞争格局

### 三种商业模式

| 模式 | 代表企业 | 特点 |
|------|---------|------|
| **全产业链** | 牧原（养殖→屠宰） | 自己养猪自己杀，内部消化，平滑猪周期 |
| **屠宰+深加工** | 双汇发展 | 采购活猪→屠宰→深加工→品牌渠道 |
| **纯屠宰** | 大量中小屠宰场 | 赚毛白差，受猪价波动影响最大 |

### 牧原的屠宰战略

| 指标 | 数据 |
|------|------|
| 2025上半年屠宰量 | 1138.9 万头（同比 +110%） |
| 占商品猪总销量 | 29.66%（同比 +11pp） |
| 6月单月屠宰 | 219.4 万头（同比 +199%，创历史新高） |

### 双汇发展的模式

2025 年全年营收 592.74 亿元，净利润 51.05 亿元，肉类产品总外销量 342 万吨。

### 行业趋势

| 趋势 | 说明 |
|------|------|
| 集约化 | 政策"减数量、提质量"，落后产能加速淘汰 |
| 智能化 | 头部企业自动化覆盖率 65%（2025年），智能分割精度达毫米级 |
| 冷鲜化 | 冷鲜肉占比从 40%（2025）向 60%（2030）提升 |
| 深加工化 | 屠宰企业向下游延伸，开发预制菜（如双汇"筷乐星厨"） |

## 6. 屠宰业务平滑猪周期的逻辑

### 核心逻辑：养殖和屠宰的利润是"跷跷板"

```
                    猪价高位期              猪价低位期
养殖环节（卖活猪）    赚大钱                  亏大钱
屠宰环节（杀猪卖肉）   利润压缩                利润扩大

纯养殖企业：          大赚 ←→ 大亏            ← 波动极大
养殖+屠宰企业：       大赚+小亏 = 中赚        小赚+大亏 = 小亏  ← 波动收窄
```

### 第一层：毛白差的反向特性

| 周期位置 | 活猪价格 | 猪肉价格 | 毛白差 | 屠宰利润 |
|---------|---------|---------|--------|---------|
| 猪价低位 | 低（12 元/kg） | 跌但跌幅小（17 元/kg） | **大**（5 元/kg） | **盈利** |
| 猪价高位 | 高（20 元/kg） | 涨但涨不动（23 元/kg） | **小**（3 元/kg） | **亏损/微利** |

### 第二层：内部转移定价——把别人的利润吃进来

纯养殖企业卖活猪给第三方屠宰场，屠宰环节的毛白差利润流失给第三方。一体化后，内部转移定价把原来流失给第三方屠宰场的利润截留了。猪价越低，养殖端亏得越多，但屠宰端赚得也越多——因为低价猪正好是屠宰的廉价原料。

### 第三层：出栏节奏的弹性

猪价低时减少外卖活猪、增加内部屠宰（以肉产品价格卖出，肉价跌幅小于活猪）；猪价高时增加外卖活猪、减少内部屠宰。

2025 年上半年，牧原内部屠宰消化了商品猪 1138.9 万头，占总销量 29.66%。

### 第四层：副产品收入——额外的利润缓冲

副产品收入可达总收入的 10-15%，受猪周期影响较小。

### 第五层：冻品库存——跨周期调节

猪价低位时大量屠宰，冻肉存一部分；猪价回升时释放冻肉库存高价卖出。冻肉可在 -18°C 保存 6-12 个月。

### 综合效果

| 周期位置 | 纯养殖利润 | 屠宰利润 | 一体化总利润 |
|---------|-----------|---------|------------|
| 猪价高位（20元/kg） | **+8元/kg** | -1元/kg | **+7元/kg** |
| 猪价低位（12元/kg） | **-2元/kg** | +5元/kg | **+3元/kg** |
| 波动幅度 | 10元/kg | 6元/kg | **4元/kg**（收窄 60%） |

> 波动越小，估值越高。

## 7. 为什么不是所有养殖企业都建屠宰

| 障碍 | 说明 |
|------|------|
| **重资产投入** | 一条现代化屠宰线投资数亿元，产能利用率低于 50% 就亏损 |
| **管理能力** | 养猪和杀猪是完全不同的生意——养殖是农业，屠宰是食品加工 |
| **渠道建设** | 屠宰产出的是肉产品，需要完全不同的销售渠道（超市、餐饮、食品厂） |
| **产能匹配** | 屠宰产能必须与养殖出栏量匹配，否则产能闲置 |
| **行业产能过剩** | 2025 年屠宰行业产能利用率仅 20-30%，此时建新屠宰线风险极高 |
